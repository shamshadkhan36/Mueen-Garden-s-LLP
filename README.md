# Mueen Garden's LLP — Luxury Landscape & Smart Irrigation Architecture

> Inspired by [Finasi Landscaping](https://www.finasi.ae/landscaping/) and tailored for **Mueen Garden's LLP** (Bengaluru, Karnataka).

Established in **2010**, Mueen Garden's LLP is a leading irrigation system service provider and turnkey landscape design-and-build company based in Harohalli, Bengaluru, Karnataka.

---

## 🌟 Key Features

- **Architectural Luxury Aesthetic:** Styled with high-end typography (Playfair Display & Plus Jakarta Sans), rich botanical greens, and champagne gold accents.
- **Finasi-Inspired Structure:**
  - Sticky glassmorphism header & top announcement bar
  - High-impact hero section with fast consultation booking
  - Trust metrics banner (15+ Years Mastery, 450+ Completed Projects, 40% Water Savings)
  - Core service disciplines (Smart Irrigation, 3D Spatial Planning, Hardscaping, Softscaping, Water Features, AMC Care)
  - Interactive Garden Style Typologies tabs (*Tropical*, *Manicured*, *Xeriscape*, *Terrace Living*)
  - Interactive Before & After touch/mouse transformation slider
  - Precision Irrigation Technology deep dive with interactive system & water savings estimator
  - Filterable portfolio masonry gallery with modal zoom
  - 5-step turnkey execution workflow
  - Verified client testimonials from Bengaluru villas and estates
  - Contact & location hub with Harohalli map snippet and direct Google Maps directions
  - Mobile-responsive floating action pills for WhatsApp and phone calls
- **Direct WhatsApp API Lead Integration:** Forms automatically format and dispatch client requirements directly to `+91 98441 35235`.

## 🚀 Getting Started

1. Clone or download this repository:
   ```bash
   git clone https://github.com/shamshadkhan36/Mueen-Garden-s-LLP.git
   ```
2. Open `index.html` directly in any web browser, or serve it with any HTTP server:
   ```bash
   python -m http.server 3000
   ```
3. Visit `http://localhost:3000` to preview the live site.
